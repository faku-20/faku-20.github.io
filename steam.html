ESP32 · Electrónica · Aplicación web

Proyecto STEAM: prototipo de riego automatizado.

Exploro una solución de control de riego para el curado de ladrillos ecológicos. Combino electrónica, sensores e interfaz web, diferenciando las pruebas del prototipo de la instalación hidráulica definitiva.

Qué funciona y qué está pendiente

El prototipo físico y el simulador Node.js son entornos de prueba diferentes.

Probado localmente

ESP32 + página web

Simulación independiente

Órdenes temporizadas y dispositivo virtual; no acciona una bomba real.

Pendiente
